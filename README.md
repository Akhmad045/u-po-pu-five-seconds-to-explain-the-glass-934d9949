One sentence, at most 200 characters, in the voice of a house cat
explaining — in the five seconds after sweeping a glass off the
table — why the glass had it coming. The glass was judging the cat's
eating habits with its silent, transparent stare, so the cat removed
the witness and the floor buried the evidence. No apology, no
confession, just the most convincing case a cat can make for itself.
`main.py` writes it to `/output/entry.txt`.

## Run

```sh
python3 main.py                  # write the line to /output/entry.txt
python3 main.py --dest out.txt   # write it somewhere else instead
python3 main.py --self-test      # check the gate, print the hash, exit
```
